Rules the systems run on

Conductor runs four of these. The rest come from agent systems built for daily operation, where an outage or a bad send costs more than a slow answer.

Code before the model

Memory lookups are deterministic. An index answers where a fact lives in about 5 ms, and the model reads only the one section that answers.

2 models

Maker and checker differ

The agent that grades work never wrote it and runs on a different model. Here the specialists run on fast tiers and the reviewer on the most capable one.

1 click

Humans own the irreversible

Anything that leaves the building passes a gate bound to the exact content approved. The demo stops for you before it writes the final answer.

0 sends

Readers cannot send

An agent that reads untrusted pages, emails or reviews holds no send rights. A prompt injection then has nowhere to go.

$0 idle

Wake on work

Agents sleep until a task is assigned, so an empty queue never spends a call. Local open-weight models carry bulk work at $0 per token; frontier models are spent on judgment.

<15 min

A watchdog outside the system

An independent process with a dead-man switch watches the orchestrator, because orchestrators fail silently.

3 levels

Plans are graphs, not lists

Work that does not depend on other work starts at once. Dependencies stay shallow so one slow agent never stalls the whole team.
